Compositor Windows 版 0.10.0 预览版

解压后运行 Compositor.exe，保留旁边的 DLL、renderer 和 third-party 文件夹。
需要 Windows 10 1903 或更新版本 / Windows 11（64 位）、.NET Framework 4.8、Microsoft Edge WebView2 Runtime。
使用时不需要 Node.js 或 Xcode。程序未签名。

右上角的 English / 简体中文 可立即切换界面语言，重启后保留设置。
项目名称、图层名称、文字内容不会因切换语言而改变。

支持图层与图层组、混合模式、蒙版、调整图层、图层效果、画笔和修饰工具、文字与形状、变换、Camera Raw、多标签项目。
支持 PNG/JPEG/WebP/BMP、TIFF、SVG、HEIC、RAW 和部分 PSD/PSB 内容导入。
PNG/JPEG 可导出；主体识别在本地运行。

0.3 新增：提交前可持续调整的渐变；选区轮廓和像素移动、复制；剪贴来源图层的烘焙/解除链接删除；链接蒙版随透视变形；Unicode 文字排版与段落框。
0.4 新增：未保存项目的自动恢复草稿；可取消的后台滤镜和缩小预览；选区像素的持续移动、缩放、旋转与透视变形。
恢复入口：View（视图）→ 恢复未保存项目，或重启后状态栏中的恢复按钮。恢复副本需要手动保存；清除应用数据也会清除恢复草稿。
Ctrl+T 自由变换选中像素，Enter 应用，Escape 取消；手机端提供同样的变换模式和应用/取消按钮。
渐变按 Mac 原版行为在应用或保存后写成像素，保存重开后不保留渐变端点参数。

Ctrl+N 新建；Ctrl+O 打开 .comp 文件夹；Ctrl+I 导入；Ctrl+S 保存。
Ctrl+Z 撤销；Ctrl+Shift+Z 重做；Ctrl+Shift+E 导出 PNG。
V 移动；B 画笔；E 橡皮擦；M 选区；T 文字；空格平移；Ctrl+滚轮缩放。

0.5 新增可编辑滤镜组、蒙版精修、分层 PSD/PSB 导出、16 位源图像、ICC 转换/软打样、RGB/CMYK TIFF、笔压/倾斜/防掌触、字体替换、动作、预设、快照和批量导出。
0.6 新增钢笔/贝塞尔路径、节点/手柄编辑、带孔子路径、路径转选区、可编辑矢量蒙版，以及手机版独立手柄开关。
0.7 新增每个滤镜的独立蒙版与强度、选区转蒙版、涂画/羽化，以及蒙版预设、动作和恢复。
0.8 新增嵌入光栅智能对象、共享内容替换/编辑，以及线性浮点 32 位 HDR TIFF 的导入、滤镜、合成与导出。HDR 界面为 SDR 色调映射预览。
新保存的项目使用版本 15 格式；仍可读取版本 1–14，旧版客户端不能打开版本 15。手机端分享的 .comp.zip 请先解压，再打开里面的 .comp 文件夹。
16 位源图像保留在项目中，画布使用 8 位预览。高精度导出最多 1600 万像素；图层效果需明确允许按 8 位渲染。尚未实现完整 32 位 HDR、原生 CMYK 通道编辑或全部 Photoshop 功能。

本版本尚未完成全部 Mac 兼容验收，尤其是 Mac 原生渲染差异、复杂 PSD、部分高级交互和大型项目性能。
自动更新、正式签名尚未配置。详细状态见源码 docs/windows-migration.md。
当前源码及本地安装包均未推送至 GitHub。

0.9.0 新增 OpenEXR 导入/导出：支持 HALF/FLOAT、ZIP/ZIPS/无压缩、通道组、数据/显示区域，以及线性 sRGB、Rec.2020、P3-D65 和 ACES 色彩转换。图像菜单可打开相应功能。内部仍是线性 sRGB 浮点编辑，界面为 SDR 预览，支持范围详见 docs/openexr.md。

0.10.0 新增 PIZ、分块、多部分和 Deep EXR；保留完整原文件，可按深度范围合成预览并原样导出。HDR 工作空间可切换，支持设备可启用扩展 HDR 显示，不支持的设备回退 SDR。新项目格式为 16。
