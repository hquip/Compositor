# Independent filter masks in preview 0.7.0

**Editable filters** now gives each filter its own mask and opacity. **Use selection as filter mask** maps the document selection, including holes and transformed layer placement, into the original layer-source box. **Add/Edit filter mask** opens a paint panel with Reveal/Hide, brush size, hardness, opacity, feathering, overlay/mask views, Reveal all, Hide all and inversion. All changes stay local until the outer filter dialog is applied. Canceling that dialog leaves the original document and undo history intact; applying a changed stack creates one undo step. Reopening and applying an unchanged stack preserves its cache and original mask files.

Filter masks use compressed grayscale PNGs, independent of the layer mask or vector-backed layer mask. White reveals a filter's effect; black keeps the preceding filter's result. Gray and the per-filter opacity blend source/result with premultiplied alpha, including filters that change transparency. Enable/disable preserves the mask for later editing; Remove discards the reference on commit. Reordering moves each mask with its filter.

The new worker stack supports all twelve adjustment kinds. Sixteen-bit filters and color-managed TIFF delivery preserve untouched least-significant source bits under black masks. This does not make the ordinary eight-bit canvas cache or PSD export sixteen-bit. Gaussian/motion blur stacks still stay within their source bounds; expanded editable-stack bounds remain outstanding.

Project saves use **format 14**, with versions 1–13 still readable. Old clients reject new saves. Windows native storage, portable phone archives, recovery checkpoints, saved-history fingerprints, layer copies, filter presets and recorded stack actions include independent mask resources. Preset/action masks retain normalized coordinates when applied to differently sized sources. Destructive pixel edits/rasterization bake filters and remove their mask resources; undo restores them.

The phone UI keeps the filter list scrollable and Apply/Cancel accessible. Mask brush/view options keep stable saved values during English/Chinese translation. Painting has immediate visual feedback; the completed stroke and final feathering use the worker result. Processing remains cancelable and resource bounded. Mask painting/feathering is raster editing; editable vector geometry inside a filter mask, mask transform handles and full Photoshop Smart Filter/Smart Object serialization are not implemented.

Mac source supports mask resources, validation, preservation, duplication, eight-bit masked filter rendering, opacity and existing-mask visibility/removal controls. Mask painting/selection generation is currently in the shared Windows/mobile editor. High-precision native Mac editing remains disabled, and Mac/iOS Xcode compilation/device acceptance remain outstanding. PSD/PSB export continues to bake filter stacks into rendered layer pixels. No repository was pushed and no physical Android device was changed.
