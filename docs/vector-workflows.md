# Editable paths in preview 0.6.0

Windows, Android and the iOS web editor share the new Pen / Path tool. Select **Paths → New path**, then tap to add straight anchors or drag to create paired Bézier handles. Tap the first anchor to close a new contour. Existing anchors and handles can be dragged; Alt-drag or the Independent handles toggle makes a handle independent; the toggle also works without a keyboard on phones. Tapping near a closed curve inserts an anchor using a de Casteljau split that preserves the curve. **Smooth / corner point** toggles its handles; **Delete point** removes it. New contour adds another closed region or a hole. Even-odd and nonzero fill rules, fill colors and rounded strokes are editable in Path style.

**Apply path** creates or updates a vector-backed image layer as one undo step. Enter applies; Escape cancels. Switching tools, saving or switching tabs commits valid drafts; incomplete drafts stay editable and report the missing points. Recovery stores unapplied drafts across restarting. Reopening and applying an unchanged path keeps the original PNG cache.

**Path to selection** uses closed contours, including holes. **Path to mask** replaces the active layer's mask with editable path geometry and a grayscale cache. **Edit vector mask** resumes editing its nodes. Mask enable/disable and linking preserve the geometry. Pixel-based mask edits, including inversion, feathering and painting, bake the mask and remove the vector metadata; undo restores both. One layer currently has one mask slot, so independent simultaneous raster and vector masks are not available.

The project format is now **13**, readable by the updated Windows/mobile readers and Mac source. Versions 1–12 remain readable; older apps reject new saves. Image and mask caches preserve appearance when opening on Mac, and its source supports geometry preservation, duplication and resizing. Native Mac path authoring and Xcode acceptance remain outstanding. The Mac app displays its PNG cache, so its scaled preview may differ from the shared editor's vector rerendering.

PNG output is flattened. PSD/PSB output explicitly converts paths to raster layers and vector masks to raster masks. Color-managed TIFF uses the embedded eight-bit vector caches, alongside the existing high-precision raster sources; paths are not a new sixteen-bit vector color engine. Layer effects also use the cached source. Shared path preview rendering is bounded to 16 megapixels per surface; large vector Photoshop exports reject allocations above that limit.

Remaining vector capabilities include imported SVG node editing, Boolean geometry operations, text on paths, artboards, full Photoshop vector/Smart Object round trips, native Mac path UI and physical stylus acceptance. This preview does not complete Photoshop equivalence. No repository was pushed and no physical Android device was changed.
